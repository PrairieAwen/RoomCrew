# 小禾 · 手绘动画样板

这是可实际导入的素材资源，包含原始透明 PNG 与 `roomcrew.avatar v2` 清单，不是界面截图。原图由内置 image_gen 工具生成，实际大小 1254×1254，64 个独立人物姿态；完整提示在项目 `doc/assets/atelier-v1-generation.txt`。PNG 原像素未修图或缩放。

本轮覆盖正背三分之四视角的走路/小跑、站坐待机、站坐玩手机、起坐及举手。西向使用作者显式允许的镜像，共 14 个动作变体；不是八个方向全部独立绘制。读写、游戏和浇花尚无此角色专用帧，按现有素材回退规则显示。

v2 的 `frame_rects` 为每个姿态声明源图裁切 `rect: [x,y,width,height]` 及统一虚拟帧内 `offset: [x,y]`。虚拟帧 192×168，脚底锚点 [96,164]，角色在世界中沿用统一尺度。制作工具分析 alpha 连通区域登记元数据，不改动原图；普通帧鞋底对齐，跑步腾空帧保留少量上下起伏。

在人物属性点击“试用手绘角色”，可以逐个选择动作、朝向和姿态，或点击“连播核心动作”。连播是明确标注的原地素材预览，不创建任务、伪造 Agent 轨迹或调用模型；点击保存后才改变人物绑定。

该图集是美术方向样板，仍可见部分 AI 生成帧的比例与手部变化；尚未完成专业逐帧修形、完整工作动作、面部独立图层、衣服换装或家具前后景拆层。
