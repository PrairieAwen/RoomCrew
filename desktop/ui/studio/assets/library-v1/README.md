# RoomCrew 首发基础素材库 v1

这是四套人物、办公家具、空间装饰与状态特效的本地素材集合。应用顶部“素材总览”可分类浏览、选择动作/朝向/站坐/表情、暂停和逐帧检查；也可用浏览器直接打开本目录 `index.html`。总览不连接模型，不持有桌面桥。

人物合计 **496 个登记姿态、每套 34 个动作变体、覆盖 20 种动作语义**；`work` 明确复用打字片段，起身与落座按反向片段复用，不把复用算成额外绘制帧。

20 种语义：待命、思考、阅读、打字、书写、工作、交谈、举手询问、汇报、提醒、倾听、走路、小跑、落座、起身、坐着、玩手机、打游戏、浇花、自定义休闲。中性、专注、疑问、担忧、微笑五种基础表情目前在**闲置站姿**提供，没有为每种动作绘制五种表情。

走跑具有原绘右前/右后方向，西向按显式镜像复用。其他方向按正式选择器选最近已有方向；读写/手机分别有站坐片段，游戏为坐姿手柄，浇花为站姿小盆栽。缺失姿态与生活动作按正式播放器回退骨架；完整矩阵以展厅实际统计为准。

**接待台、工位、会议桌、沙发、书架、文件柜、冰箱、大屏、绿植与灯/咖啡机已接入房间，茶几原图复用于低矮安全服务台。** 办公椅仍保留矢量接触层，其余装饰与原图特效目前用于总览，详情按真实用途标注。碰撞、格网和人工交互保持原合同，专业桌椅前后景拆层仍需完善。监管员依然是安全服务形象，素材不产生 Agent 或权限。

## 文件组织与自定义

```text
characters/<owner|assistant|employee|guardian>/
  core.png       透明基础动作原图
  work.png       透明工作/生活动作原图
  avatar.json    可直接导入的 v3 两页动作清单
objects/
  furniture.png  12 件家具原图
  decor.png      16 件装饰原图
  effects.png    8 组四帧特效原图
catalog.json     可核查的完整登记与裁切
catalog.js       同份登记的离线浏览版本
index.html       本地素材总览
gallery.js/css   展厅交互与样式
```

人物属性里选择随附角色再点击“导入完整角色”，预览后保存绑定。美术角色可用于不同人物，不改变身份或能力；已有用户绑定不会自动覆盖。自制素材可复制一个角色目录、替换 PNG 后更新每帧裁切、缩放、脚底锚点和动作清单，通过“导入素材”选 `avatar.json`。不能只换图片保留旧裁切坐标。

## 统一约束

- 柔和手绘 Q 版，固定 2.5D 视角、柔和左上光、相同轮廓与色系；角色足底固定、坐姿不拿站姿代替。
- v1 等格、v2 单页裁切继续兼容；v3 仅一至两张 PNG，每张编码不超过 4 MiB、边长 32—2048，不接受 APNG。清单不超过 128 KiB。
- v3 每项 `frame_rects` 为 `{page,rect:[x,y,w,h],offset:[x,y],scale}`，最多 512 项；`page` 是合法页号，`scale` 是 0.25—2 的有限数值，裁切边长不超过 512，缩放后必须位于虚拟帧内。虚拟帧最大 512×512。
- 动作片段最多 128 项，总引用最多 2048；每片段 1—120 帧、1—60 FPS，必须有站立 idle。仅有限动作/姿态/方向/表情词表，不支持素材脚本。
- 文件名只可引用同目录 PNG，拒绝 URL、目录、设备名和重复页。导入时规范化、去元数据、原子复制，所有页共同参与内容 hash。
- 场景最多同时使用 8 套自制图集；含预览的解码缓存最多 9 套。两页最多约 32 MiB RGBA/套，实际四套原图约 48 MiB 解码像素，浏览器与 data URL 会有额外开销。展厅按类别按需加载，可见卡片限频约 10 FPS；关闭会卸载 iframe。

## 来源、复现与美术缺口

采用 **imagegen 内置工具**生成透明 PNG；本目录保留原始像素。小禾基础页沿用上一版已认可样板，其他页按同一画风生成。提示与来源保存在 `doc/assets/library-v1-generation.json`、`doc/assets/library-v1-environment-generation.json` 和 `doc/assets/atelier-v1-generation.txt`，没有外部下载素材。

`desktop/tools/python/build_material_library.py` 只分析透明度、登记裁切/锚点/尺度，生成清单与覆盖统计，并走生产导入器复验；不重画、不修改 PNG。已有两页之间仍可能存在造型/比例变化、少量边缘触及、过渡抖动和道具接触误差，展厅标明需精修的姿态，不能把 496 帧等同专业逐帧动画。下一步优先做人物轮廓与锚点人工精修，再补缺失站坐/方向组合和家具分层，继续完善房间分层与接触。
