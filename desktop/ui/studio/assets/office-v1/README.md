# 办公交互补充素材 v1

**已停用：当前运行改用 scene-v1 的统一八向合同。本目录仅保留历史生成来源，不参与运行或发行打包。**

使用内置 imagegen 工具制作，原图和实际提示词保存在本目录；原先四套人物 core.png / work.png 不修改。

2026-10-27 更新：默认电脑桌和安全台现使用 desks-v2.png 的同款浅木色桌型，两个图共用正交 2:1 视角、西北工作面、112 世界单位宽度及同一接触注册。旧 fixtures.png 中的双屏台不再接入场景，其余椅子/柜子仍使用该图。

监管员改用 guardian-v2.png 的六帧直立坐姿，背向四帧及侧/正面帧共用同一缩放，避免逐帧身体比例变化。实际内置生成工具、参考及完整提示词保存在 prompts-v2.json；对应裁切与尺寸由 register_office_art.py 只读分析生成。两个新版 PNG 的透明像素和源尺寸保持原样，不通过斜切或压扁人物制造朝向。

- actions.png：四个角色的背向坐姿与侧转。原图每行八个姿势，但最后两列边缘相接，未接入；仅登记前六列，共 24 个完整姿势。每个角色使用四帧背向工作循环、一个侧向坐姿和一个面向用户的坐姿。起坐复用原来的背向站姿与新坐姿，并配合运动阶段与短混合，不宣称新做了完整骨骼动画。
- fixtures.png：背面办公椅、安全控制台、档案柜组、侧面办公椅。安全台是未来权限服务的场景入口，当前未接入 VM；档案柜不自动归档或调用记忆。
- catalog.js：`packaging/register_office_art.py` 只读测量透明轮廓并生成的裁切、头部尺度及四套已知内置素材的内容 ID，不重绘像素。
- prompts.json：本次生成使用的提示词和参考图片。

`office-behavior.js` 只为精确匹配的内置素材 ID 在内存附加显示片段。原清单、原帧号、已保存素材、用户两页图集导入合同和显式动作绑定保持原样；自制素材不会因为同名而被替换。正面帧不能作为自动背向工作回退，缺背向工作帧时优先保持同姿态背向 idle。显式绑定须兼容实际工作朝向，不兼容时仅在显示层回退，原配置不改。

新帧按与原播放器相同的头宽约 38 世界单位、统一脚底和等比缩放约束注册。普通工位和安全台的实际工作方向均为西北；原图东北帧通过清单明确允许的西向镜像适配。短转向先停止手部动作，经过侧向坐姿后恢复工作或休闲。背向椅背只在腰部以下遮挡角色，不覆盖大头角色的头部。

修改图片或原内置人物清单后，运行 `.venv/Scripts/python.exe packaging/register_office_art.py` 重建内容指纹及坐标；随后运行 office-behavior.test.cjs、相关 Python 测试和原生 office_scene_smoke.py。PNG 的自动生成帧仍有美术细节限制，不等于八向商业游戏动作全集。
