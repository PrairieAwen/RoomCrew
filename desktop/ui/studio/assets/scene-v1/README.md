# 场景素材 v1

2026-10-28 最新八类设备和四角色配套交互已经从 `../scene-v2/` 接入；本目录仍保存统一运行合同和历史来源。最新范围与未完成项见 `../scene-v2/README.md` 及 ADR-0020。下方“尚未重制”是此前状态，不覆盖新批次的兼容预览声明。

**制作与验收基线已更新：** 后续素材使用项目 `doc/assets/asset-production-standard/README.md`。现有原图存在与地面投影不一致的问题，尚未按新规范重制或通过视觉验收；下方历史功能检查不等于原图轴线、连续动画与全部接触合格。新规范不自动改变当前导入合同。

此目录是当前运行素材。合同和边界见 `doc/architecture/0017-configurable-scene-assets.md`。

2026-10-28 的现行工位预设见 ADR-0019：`paired-chair-v1.png` 为四角色配套椅与工作姿势，`chair-rise-v2.png` 为四角色各六帧起坐，`workstation-v3.png` 为无键盘桌子及独立键盘。原图来源与可恢复的生成描述记录在 `generation-v3.json`，使用内置 image_gen；旧记录保留追溯，不把生成描述冒称逐字原词。内部显示现在是三张补页、总共五页，用户源两页合同不变。配套仅适用于匹配角色与标准座高 22 的办公椅；不能据此宣称全家具自动贴合。下方两补页/四页说明属于 ADR-0018 历史记录。

2026-10-27 第二轮以用户提供的暖色办公室参考重校：放大沙发/茶几/桌面、重新校准椅背和会议桌落地线，保留统一人物头宽；`working-v2.png` 为四角色各两向、每向两帧的伸手工作补图，`window-garden-v2.png` 为窗外树景纹理。两者由内置 image_gen 生成，完整提示词和身份见 `generation-v2.json`。

内置显示现可使用两张受限补充页（坐姿与工作），共四个显示页；用户原两页导入合同及原清单不变。工作补图不代表其他六向完整工作动画。当前默认显示高度：桌 94、椅 48、沙发 94、茶几 54、会议桌 114 世界单位；接触与相对比例还需结合真实画面检验，不能只靠数值判定协调。

- `catalog.json` 是统一事实；`catalog.js` 为完全相同 JSON 的浏览器只读包装。
- 14 类设备：12 类有八方向原绘槽，监管台复用电脑桌；另两类绿植和圆灯明确声明对称复用。
- 11 张新设备 PNG、4 张人物坐姿 PNG；每张四列两行，实际方向顺序由目录指定，不应按提示词猜测。
- 四套人物各八个接触基准姿态。它们不是所有动作的八方向完整循环，原有站姿与走跑素材仍保留。
- `index.html` / `inspector.js` 提供真实原图和接触标记预览；绿点臀部、蓝点脚底。
- `prompts.json` 记录内置 image_gen 的提示词、引用及生成身份；所有原图直接保存，不经 Python 修图。

在项目根运行 `.venv/Scripts/python.exe packaging/register_scene_assets.py` 可重新登记裁切与元数据。脚本只分析透明轮廓，不改变 PNG；改动作者标记后应运行方向、接触和原生场景验证。

用户图集的 hip / soles 使用虚拟帧坐标；本目录内部补帧使用已换算的世界局部标记和 seat_height。两者不能混用。家具的 operator_ground / seat 相对各自源矩形登记，桌子各方向分别设置操作面。

当前已开放内置设备的位置、方向与座高编辑及用户人物图集导入；外部家具导入、手部 IK、骨骼编辑器、家具拖拽未实现。
