人物必须提供什么

可导入的草稿至少有站立待命；完整可配置素材应覆盖八方向的站立、行走、起身、落座、坐姿待命和工作关键帧，以及提问、完成、报错等表现。跑步、电话、读书、游戏和个人摸鱼可逐步增加。

本轮四套内置人物已补八向坐姿关键帧；这些是接触与朝向基准，并非每个动作都已制作完整八向逐帧动画。未制作的动作会复用兼容姿态，不能把一个关键帧说成完整动画。

坐姿每帧可标注 contact.hip 和 contact.soles，可补 hands、bubble。坐标位于虚拟帧，原图等比缩放；臀部对应座面，脚底对应地面或可见脚踏。绿点为臀部，蓝点为脚底。

家具必须声明八个方向槽、源矩形、世界尺度、落地线、占地与交互点。绿植和圆灯可声明旋转对称复用；不允许用同一张正面图冒充已经制作了设备背面。
