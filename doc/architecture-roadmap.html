L4 / 18

第一条纵向切片：做通一个闭环再扩张

切片检查点必须看到的结果
人物老板可坐沙发；A 能去当前接待位，动画不阻塞输入；真实资源缺失有明确状态。
任务父任务和复核依赖正确；A 完成不会错误结束 B；每个步骤有身份与预算。
执行代码确实在本机隔离域运行，日志和产物可核验；失败与取消有实际结果。
数据重启可恢复已提交成果；双空间同名数据不串用，旧回包不会覆盖当前视图。
安全不将原始秘密写入宿主脚本 / prompt；新增敏感能力走独立批准。
云模型接入的一个前置细化

W04 若选真实云模型，需要先具备受信任 Vault 模型凭据连接器。可把 W05 的这项最小前置子任务提前到 W03 / W04；完整批准、撤销和关闭屏障仍在 W05 完成。也可先用已验证的本地模型。协议回放只证明工具链，不算真实模型验收；不能用宿主明文密钥 shortcut。

W02 人物动作纵切片三角色、沙发 / 办公椅 / 会议椅、接待、换座与遮挡。真实动作资源与录屏；重复点击、窗口恢复、A/B 切换无串态。W01；美术 PoC。
W03 隔离与文件网关WHPX / QEMU、实例引导、限制网络、job、输入输出、真实停止。目标机探针、越域 / 直连拒绝、异常停止和文件提交恢复。W00 / W01；虚拟化 PoC。
W04 单 Agent 真任务模型适配器、代码包、工具循环、预算 / 超时、证据与产物。一份合成资料生成报告；真实代码执行、失败 / 取消 / 恢复。W01 / W03。
W05 人工与安全Intervention、Vault、审批、逐次使用和关闭屏障。普通选择不授予权限；在途 / 失联 / 跨空间审批均正确。W04。
W06 协作与 MCP助手分派、持久邮箱、复核、有限会议、MCP 发现 / 变化。A 写代码、B 按 hash 复核，成果回老板；消息与人物映射贯通。W02 / W04 / W05。
W07 可靠性与厂商迁移多协议 adapter、切换 checkpoint、上下文压缩、诊断防循环。两种协议的合同 / 实际能力证据、迟到隔离、无进展停止与上下文回退。W04 / W05 / W06。
W08 登录 Browser / Computer Use人工 private 登录、观察—动作、受限账号浏览、无凭据 Desktop PoC。凭据不进模型；接管 / 坐标 / 失联 / 关闭真实验证。W03 / W05 / W07；安全门槛全过。
W09 发行与开放创作素材校验器、技能安装、更新签名、迁移、备份、诊断。干净 Windows 安装包、目标 GPU / DPI / 内存矩阵与安全回归。前置能力各自通过；不以未过功能的开关掩盖边界破坏。

阶段计划保留 v1.4 的 W00–W09 编号。W06 可以形成内部技术预览，但公开分发仍需 W09 安装包与对应能力门槛；登录 / 电脑操作只有 W08 通过后才能声明可用。若首发收窄功能，必须同步产品范围、开关和验收，不以 mock 冒充未完成能力。

先减少高风险未知：不用等完整系统才验证

PoC最小输入输出与退出条件
人物 / 图形3 个可就座角色，沙发 / 办公椅 / 会议椅，固定测试布局。资源 manifest、录屏、关键帧日志、DPI 与驻留预算；换座和中断不能错位。
VM / 出口固定镜像、guest agent、合成文件与测试端点，无真实用户秘密。目标机矩阵、引导 / 身份 / 控制日志、拒绝网络与越界文件的真实证据。
harness / 模型一份资料 → 程序 → 报告 → 验证的相同合同。覆盖恢复 / 等批 / 取消、端点差异、数据出口和实现修改成本，再冻结选择。

16 GB / 32 GB、12 角色 / 40 件家具、帧耗时和纹理预算都是测试档位或目标，不是已经确认的最低配置与性能成绩。

接下来具体做什么：第一批工作与交付清单

顺序动作应交付的东西进入下一步的条件
1固定首发范围与第一条任务一页 scope、非目标、合成输入、成功 / 失败 / 取消标准。团队和开发 AI 对“完成”有相同定义。
2完成 W00 仓库骨架AGENTS.md、docs、schema、verify wrapper、依赖 / 构建记录。干净环境可重复运行检查；缺失环境记录 NOT_RUN。
3A人物 / 渲染 PoC三角色三座具动作包、关键帧与遮挡录屏、资源预算。可坐、可起、可换座、可中断；图形环境结果可追。
3BVM / 网络 PoC固定镜像、实例身份、文件交换、网络与越界探针日志。目标机器能启动，禁止路径实际失败；无 VM 不转宿主执行。
3C有界 harness 比较同一工作流 / 工具网关的实现与恢复 / 取消结果。决定保留小型 loop 或选受控框架适配器。
4复盘并冻结第一轮基线锁版清单、支持矩阵、首发能力、剩余风险与后续估算。不通过的能力收窄或更换方案。
5按 W01–W04 实现纵切片独立工作空间、场景 / 数据 / 执行真实贯通。能演示成果，同时能拒绝、取消和恢复。
6再进入 W05–W09人工 / 安全、协作、可靠性、账号、发行。逐项门槛通过；未启用的能力明确不承诺。
第一次技术复盘只回答四件事
  • 目标 Windows 上图形与 VM 是否可行？
  • 完整人物资源能否按统一合同制作并维持预算？
  • 最小任务是否有可信成果、可取消、可恢复？
  • 哪些技术可锁版，哪些能力需要缩小或改选？
