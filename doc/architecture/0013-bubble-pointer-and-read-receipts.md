# ADR-0013：泡泡真实点击与会话已读

状态：已实现；2026-10-27。更新 ADR-0010 的完成回执语义；Agent 执行与后端任务状态不变。

## 原因

泡泡移入独立 SVG 图层后，不再是 .crew-avatar 的后代。相机只排除人物与家具，误把泡泡的 pointerdown 当作空地平移，setPointerCapture 将随后事件重定向到 SVG，按钮收不到真实 click。直接调用 bubbleButton.click() 的旧验证绕过指针路径，没有覆盖此问题。

另一个问题是同一人物、同一会话可能有多轮已完成任务。整个会话已加载，但回执仅确认一条，下一条使用相同文案再次显示，看起来未消失。

## 当前行为

- 相机主键平移排除人物、家具、button、a、input、select、textarea 与 role=button 的祖先；点击泡泡不捕获指针，空地与中键平移保留。
- 控制器固定人物、通知、会话与工作空间代次，成功加载轨迹和产物后，将实际 state.cursor 作为 through_seq 传入桌面 acknowledge_bubble。加载失败或切空间不发送回执。
- bubbles.sqlite 在一个事务中确认该人物、该会话、source_seq 不超过实际展示游标的 pending 完成结果。原两参数接口仍只确认单条；新参数必须为有效整数且覆盖点击通知。回执幂等，不修改业务执行状态。
- 其他人物、其他会话、未答人工问题及游标之后新产生的结果不被确认。若该人物另有其他会话的未读结果，界面提示该原因，不能把所有提示静默清空。
- 人工表单只打开或关闭时保留泡泡；真实答复解除原问题。任务继续执行后可以产生新的完成提示，查看新结果才清除。
- 原有每空间独立回执数据库继续使用，无需清理历史数据或重置用户配置；已读状态跨重启保持。

## 验证

16 项 Python 回归通过，包含同会话批量确认、另人物/另会话隔离、人工问题保留、晚到结果、无效游标、幂等、迁移与重启。七组 Node 回归及 Ruff、desktop/src 的 mypy 检查通过。

desktop/tests/bubble_pointer_smoke.py 在独立目录运行真实 Deep Agents 和本机合成模型，等待 computer-use 对原生 WebView2 窗口进行实际鼠标操作；不调用泡泡 element.click()。四次可信 pointerdown、四次模型请求完整验证：两轮同会话结果一次消失、人工问题打开后关闭仍保留、重新打开并提交恢复原执行、最终完成再次点击消失；重新创建 Runtime 后仍无已读泡泡。真实鼠标操作由外部执行，脚本不是无需交互的自动测试。

旧的 DOM 点击测试继续检查读取失败和工作空间切换；新增 camera-pointer.test.cjs 专门检查相机输入归属。后续泡泡移动、分层或相机修改都应保留真实指针验收。

Windows 独立程序已完整重建并启动。在实际发行版中通过真实鼠标查看阿晨的两个历史会话，三条完成结果分别按会话确认，最终人物泡泡消失；未查看的小岚结果仍保留。发行 ZIP 共 421 项，CRC 通过，52 个界面资源与源码一致，不包含用户数据库或密文。ZIP SHA256：029771f18015f5ab4d6403bde66fafde5d3fc5f5bca4691820d4b559b0851b6d。
