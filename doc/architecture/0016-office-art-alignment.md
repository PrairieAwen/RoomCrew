# ADR-0016：桌子与监管员的统一视觉

后续覆盖：当前默认资源、坐姿高度和方向合同已由 [ADR-0017](0017-configurable-scene-assets.md) 替代。下文保留历史验收；office-v1 不再参与运行和打包。

状态：2026-10-27；只修改桌面资源、家具接触注册与原生验证，不改变 Agent 权限或任务事实。

原普通桌和双屏监管台由不同图集生成，透视与朝向不一致。监管员又复用了前倾工作姿势，单独调整摆放坐标仍不能解决“歪”的观感。

## 当前方案

内置 image_gen 分别制作两张实际透明 PNG，保存在 desktop/ui/studio/assets/office-v1：

- desks-v2.png：两款同一机位、同一轮廓的浅木桌，浅蓝单屏、直立桌腿、左侧小抽屉和右侧膝部空位；监管台只在屏幕图案和一本笔记本上区别。按正交 2:1 设计，并目检桌面平行边、显示器及桌腿，不用旋转整张平面图伪装朝向。
- guardian-v2.png：六帧直立坐姿，背向工作四帧、侧向和正面各一帧。六帧使用同一等比缩放，保留原角色蓝发、眼镜和衣着；不增加发光或悬浮效果。

完整提示词、参考图片及工具记录在同目录 prompts-v2.json。register_office_art.py 仅读透明轮廓生成裁切元数据，不修图、不更改源像素。旧 fixtures.png 保留，因为椅子与档案柜仍需使用；其中旧双屏台的注册已由新图替换，不维护两套默认安全台。

## 接触与方向

两种桌子共用 material.contact：宽度 112，座点相对原图为 [0.74, 0.94]，工作方向西北。家具绘制统一读取该元数据，不再为安全台使用另一组手调坐标。

桌面 SceneStore 生成相同操作侧的格心锚点。监管员沿用 guardian-station 身份，进入右侧操作位置并朝西北显示器；原持久化锚点 ID、用户素材 ID、原帧号和两页导入合同不改。新版监管员补图仅为已知内置内容 ID 增加一页显示资源，路径仍有固定白名单；自制角色不被替换。

身体的坐姿抬升、泡泡跟随和分层遮挡沿用 ADR-0015。监管台仍显示未接入，没有因此开放安全 VM、审核或 Agent 执行能力。

## 验证

117 项 Python 回归、8 组 Node、Ruff 与 mypy 通过。新增检查同视角桌型及接触参数、监管员共享缩放和实际补图路径。

两轮原生 WebView 验收均经过真实 Deep Agents、隔离 Python、人工答复恢复和连续换座，采用本机合成模型而非用户 Key。第二轮直接检查渲染 DOM 的图片宽高比与世界变换，确认未非等比缩放、旋转或斜切；也检查监管员实际使用新页、西北方向和镜像，而不只看资源文件。工作、入座与行走截图已目检，连续脚点侵入计数为零。

Windows 独立程序已重建、发布并启动，已查看安装版本的完整会议室。原用户会话状态计数在重启前后保持一致。ZIP 共 430 项，CRC 通过；61 个 UI 文件与源码和安装目录逐字节一致。SHA256：`13beae6ff30b7bfabef18aa76cadf5511c043ba12ae1579a30fdfdf32975e995`。

图集仍是有限方向的手绘素材，检查结果不代表任意自制图集自动满足同一透视。旧素材总览保留原始图集，场景默认使用本页的显示补充。
