01

整体：RoomCrew 管理运行，Deep Agents 执行循环

当前不是自己重写的 Agent Loop。RoomCrew 把工作空间、身份、配置和能力装配好，再把一次任务交给 Deep Agents；后台产出的事件交给调用方读取。

架构边界：后端没有人物动作、泡泡或家具协议。桌面只读消费执行事实；运行结果不由动画决定。下文只展开 Agent 底座。
层项目负责框架负责
用例与运行空间、会话、定义快照、请求幂等、Run 终态不负责 RoomCrew 业务表
Agent 执行选择模型代理、工具、Skills、中间件并适配事件模型—工具循环、主子图、标准消息、interrupt、checkpoint
观察与恢复保存官方事件及产品投影，提供查询保存图的可恢复状态；不等同于产品轨迹
02

定义 → 身份 → Run：同一配置可以复用，执行状态不能复用

agent_id 标识可复用定义，member_id 标识接单身份；每轮任务有单独的产品 Run。工厂使用该 Run 保存的快照，避免用户编辑配置改变在途任务。

标识含义关系与边界
workspace_id工作空间独立 Runtime、配置名单、SQLite 与会话文件；private 模型配置用户级共享
agent_id执行定义提示词、能力、版本；不能当作消息上下文的主键
member_id接单身份多个身份可复用一份 Agent 定义；监管员不执行 Agent 任务
conversation_id会话可含多轮产品 Run；同一会话下的参与者共用产物目录
产品 run_id一次用户任务新请求生成，人工恢复沿用；绑定身份快照、累计额度和事件
thread_id框架主线程助手沿用 conversation_id；其他入口为 conversation_id::member_id
SDK run_id / tool_call_id内部调用与模型工具请求与产品 Run 不同；用于调用树及工具结果配对

每次执行和人工恢复都会新建工厂及模型连接。snapshot 固定配置，checkpoint 恢复消息/图状态；两者配合。所有 Agent 当前绑定 execution:default，尚未提供逐 Agent 选择不同模型。

03

一次任务：模型决定下一步，工具产生真实结果

主 Agent 可以自己使用工具，也可以先通过 list_agents 查看名单，再通过 task 委派。意图理解由当前接单 Agent 完成，项目没有另设一条常驻的意图识别循环。

可协作的内容

  • 委派描述、子任务最终结果、共享任务文件。
  • 主 Agent 汇总最终答复；各执行者轨迹保留真实身份。
  • 不同成员的子任务可由 SDK 调度；同一成员不能被并发克隆。

当前不是无限 Agent 网络

  • 名单来自本空间的已启用成员及独立定义。
  • 未实现任意生成新员工或无限递归委派。
  • 当前主子 Agent 共用一次执行模型代理；不是一人一个独立服务。
04

上下文：消息分别维护，文件与额度有明确共享范围

“独立 Agent”不等于每个角色都创建一个 OS 进程或单独的数据库。当前主要是同一应用内的图/协程、各自的消息状态，以及按任务划分的资源。

资源实际范围需要理解的限制
消息与摘要各图/子 Agent 的消息状态主线程按会话与入口身份定位；不要用 agent_id 合并历史
任务文件conversation_id同会话主子可交流产物；它不是自动冲突合并或事务文件系统
模型与额度同一产品 Run；人工恢复从已用次数重建共用总次数，摘要也计入；不按每个子 Agent 重置
Python 执行锁一次工厂装配该图脚本串行；普通文件读写不因此获得通用文件锁
MCP 发现缓存一次工厂装配同配置减少重复发现；不跨 Run 全局缓存工具会话
模型秘密User 私有目录，由可信工厂读取不挂载到任务文件视图；不是已经完成的凭据安全 VM
跨空间长期记忆尚未实现档案室当前不参与执行，也不会自动提取习惯

压缩位置：middleware.stack 为各 Agent 建独立 ToolIdentityMiddleware 与官方摘要中间件；按同名槽位替换默认摘要，不叠第二套。触发/保留阈值由 SDK 结合模型窗口决定，CompressionPolicy 只提供摘要输入裁剪预算和可选提示。压缩后仍超限则转为 CONTEXT_LIMIT。

05

能力接入：工具、MCP、Skills、代码执行各有独立位置

工具是模型可以调用的操作；MCP 是外部工具的接入方式；Skills 是按需读取的说明及附带文件。三者不应该混成一种配置，也不应把脚本执行塞进 Loop 本身。

能力装配 / 实现位置当前状态
规划与文本文件SDK 默认工具 + tools.registry.file_backend真实文件列表、读写、编辑和搜索；没有宿主 Shell 后端
补充文件工具tools/files.pyfile_info / make_directory / copy_file / move_file / delete_file
成员与人工tools/agents.py、tools/human.pylist_agents 是快照目录；ask_user 是真正 interrupt
MCPmcp/provider.py官方 MultiServerMCPClient；无认证 Streamable HTTP；名称带服务前缀
Skillsskills/registry.py + 只读文件路由显式来源、渐进读取，不自动扫描整个磁盘；不是脚本自动执行授权
Pythontools/python.py → security/appcontainer.py随包标准库，不依赖用户安装；不能当作完整编码环境
扩展点AgentLoopFactory._components组合已有能力，避免为不同员工复制工具注册或构图代码

MCP 发现有独立 20 秒外层期限，HTTP 连接/读取分别配置 15/45 秒；单次发现最多 64 个工具。当前没有 stdio、OAuth 或认证 Header 支持。Python 默认 30 秒、最高 120 秒；不支持 pip、第三方库、外网、子进程；隔离不可用直接失败，不回退宿主执行。脚本删除语义并非完整镜像同步，目前回收新增或变更文件。

06

人工介入：持久暂停，再恢复同一个 Run

遇到必须由用户决定的问题，Agent 调用 ask_user。程序保存官方中断和产品待办；答复通过 Command(resume=…) 返回原调用，不另开一个任务猜测结果。

  • 等待人工后 active 协程结束、连接释放，Run 保留 waiting_user；回答时按原快照重新构图，累计额度继续扣减。
  • request_id 对应真实 interrupt，command_id 用于回答幂等；问题取消或过期不能继续恢复。
  • 同空间已有其他活跃任务时，人工恢复需要稍后再提交。等待状态本身不占 active 执行槽。
  • 工具中断前不放副作用，因为恢复可能重放该工具。ask_user 的 approval 是信息确认类型，不是 OS 权限或安全 VM 授权。
07

轨迹与 checkpoint：同源执行事实，承担不同职责

轨迹告诉你发生过什么，checkpoint 保存执行到哪里。不能只用事件日志替代图恢复，也不能让客户端直接读取和修改框架状态表。

存储当前内容主要消费者
account.sqliteagent_definitions、members、preferences可信配置入口、AccountService、执行快照
sessions.sqliteconversations、runs、events、native_events、run_bindings、human_requests产品查询、幂等、人工问题、额度与身份对账
runtime.sqlite官方 AsyncSqliteSaver 的 checkpoint 表及 writes框架恢复；RoomCrew 不手工拼这些表
sessions/<conversation_id>/files真实任务文件与产物文件工具、Python、副产物查询
data/skill-bundles/<hash>已配置 Skills 的版本化文本包只读 Skills 文件路由
private/model-config.dpapi用户模型真实配置，当前 Windows 用户保护可信配置与模型工厂，不能当作 Agent 工具开放
调用树与顺序：SDK run_id 标识一次内部调用，parent_ids 是从根到直接父调用的祖先路径，不是多个直接父亲。native_events 另存 parent_run_id = parent_ids[-1] 便于索引。seq 只保证该表的入库接收顺序，不能把并行调用强行解释成串行；两张事件表的 seq 也不能直接相互比较。

官方事件采用受控序列化：不保存逐 token 的 *_stream 事件；图节点的 on_chain_* 保留生命周期头而清空重复 data；标准模型/工具载荷保留并脱敏。因此这里是“官方事件结构的受控持久化”，不是未经处理的 SDK 全量转储，更不是隐藏思维链。

08

运行生命周期、并发和失败边界

产品 Run 由 ExecutionService 管理，框架图节点由 SDK 管理。当前是本地任务框架，不是分布式队列，也没有失败后无限重试或自动恢复未知外部副作用。

约束当前值 / 行为代码位置
空间并发每空间最多一个 active 执行；Hub 最多四个空间同时活跃application/workspaces.py、execution.py
成员并发主图内每个配置目标一次执行租约；按 member_id 限制，不按 agent_id 合并middleware/delegation.py
模型调用默认最多 32 次，主子与摘要共用，失败请求也计入contracts/limits.py、middleware/limits.py
运行预算默认 600 秒，人工等待不计；恢复累计消耗。执行阶段使用剩余超时，装配各有自身边界application/execution.py、storage/run_state.py
图步数recursion_limit 默认 80；不是调用树深度或 Agent 数量contracts/limits.py、agent_loop/engine.py
请求超时模型默认 90 秒，可配置 10–600；SDK 自动重试关闭config/validation.py、models/factory.py
上下文默认窗口 32768 Token，按实际模型人工填写；SDK 摘要后仍超限会失败config/schema.py、context_compression/
继续与恢复成功会话可续聊；人工恢复沿原 Run；失败/取消/重启中断会话需新建继续application/execution.py、storage/sessions.py

waiting_user 会话可以跨重启保留；重启时尚处 running 的 Run 被标为 interrupted，不自动重放。当前没有统一工具级自动重试、死循环反思诊断器、分布式队列、完整编码依赖环境或跨空间长期记忆。

尚未实现

本文按当前源码整理，不启动模型、不读取用户配置、不改变执行行为。历史背景：ADR-0008、ADR-0009、ADR-0021。源码更新后应同步复核本图中的职责和边界。
