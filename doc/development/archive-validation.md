候选 exe 在独立合成档案目录启动，实际通过 computer-use 打开档案室、选择 **“语义向量”**，输入“家里养的宠物是什么品种的狗？”，成功显示四项相关笔记/原文片段。该输入与原文不是精确字符串匹配，因此验证的是冻结包内的真实 ONNX 查询路径。

随包模型文件 `model_optimized.onnx` 为 94,781,076 字节，附 tokenizer、配置、公开版本清单；使用 CPU，运行时只读本地资源，没有要求新 embedding Key、GPU、用户 Python 或常驻向量数据库。冻结检查使用合成模型配置，查询不依赖活跃的远程模型服务。不是只检查“模型文件存在”后就宣称打包语义可用。

通过 `packaging/publish.ps1` 发布，活动发行 `20261029-134611`；`start.ps1 -Check` 指向原应用数据目录。最终 UI 与源码哈希、模型资源哈希、ZIP CRC 与不携带用户私有数据另做发行检查。签名、安装器及干净 Windows 机器兼容性仍不属于这次已完成验收。

## 5. 使用与限制

- 左侧“档案室”或画布档案柜进入；关键词、语义、日期、成员过滤，查看来源消息，必要时继续分页。
- 自动归档只在应用运行且电脑清醒时检查。也可在档案室主动归档当前已完成会话；有活动或人工问题会明确拒绝。
- 再次和人物聊天无需手工换会话；显式“新建会话”仍创建独立任务，不覆盖其他并行上下文。
- 摘要仍调用已配置模型，后台最多十二次/小时；文本和本地向量查询不调用远程模型。摘要误读仍可能发生，重要事实必须核对保留原文。
- 跨空间需用户手动选来源；不能由 Agent 通过工具开放权限。撤销只阻止后续查询，不删除已经进入过去对话的内容。
- 未实现空间/档案删除、云同步、自动长期偏好提取、二进制附件全文解析或自动保留期清理；原产物目录保留，未批量复制到档案副本。
