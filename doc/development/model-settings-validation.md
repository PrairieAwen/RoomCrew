# 当前表单保存与连接测试修复验收

日期：2026-10-27。原问题：表单改了但未保存，旧按钮仍调用磁盘配置，造成屏幕上的新地址与实际测试地址不一致。

现主入口为「保存并测试连接」，另提供「仅保存配置」。当前输入保存成功后才探测；保存失败不探测旧值。编辑字段清除旧成功提示，操作期间锁定编辑和重复点击；关闭、切换用途或空间后旧回调不能覆盖新表单。无修改测试不保存，内容完全相同的显式保存也保留原 reference 和密文。
