RoomCrew · 本地交互原型 0.1

运行：解压整个目录，双击 RoomCrew.exe。请保留旁边的 _internal 文件夹。
无需另外安装 Python、Node.js 或数据库服务。
系统要求：Windows x64，Microsoft Edge WebView2 Runtime 和 .NET Framework 4.8。
首版未做代码签名；如系统策略阻止运行，请联系开发者，不要关闭系统安全保护。

工作空间：
左侧“我的空间”可新建、选择和重命名工作空间，每个空间对应一间会议室。
选择后主画布切换会议室，原空间的后台任务继续执行，侧栏显示执行与待答复数量。
成员、布局、会话、轨迹、文件分别保存；模型连接配置由本机用户统一维护。
原数据属于默认工作空间，位置不变；新空间数据保存在 workspaces\<空间ID>\data。
当前最多 16 个空间，未提供删除空间与云同步。共享模型配置修改前需完成所有空间的运行与待答复。

首次验证：
1. 打开“模型配置”，手动填写 Base URL、模型 ID、API Key、超时与上下文窗口。
2. 当前支持 OpenAI 兼容 Chat Completions，模型必须支持标准工具调用。
   如需要本机代理，请填写“代理地址”；留空直连，不自动继承系统代理。
3. 点“保存并测试连接”，自动先保存当前填写的配置，再发起一次模型请求。无需先单独保存。
   “仅保存配置”只在本机保存，不发模型请求；保存失败时不会继续测试旧配置。
   未修改时重复测试不改变模型绑定；修改字段后，旧成功提示会清除。
4. 可在“我的团队”添加成员；用成员选择框或 @准确名字 指派任务。默认助手可以自主委派已配置员工。
5. 点人物查看事项，再点“执行轨迹”查看他的所有子任务；顶部“会话”显示完整会话与产物。
6. 可以让助手写日记；内容完全由模型和真实工具完成，没有预设日记结果。
7. 顶部“待答复”处理真实 ask_user 信息确认；答复后沿用原 Run 恢复，可以正常关闭应用后再回答。
8. 工作室铺满窗口，可拖动空地、滚轮缩放，导航与团队是悬浮抽屉。点击人物后，再点沙发或工位可换座；“布置会议室”用格网坐标添加、移动家具。走路不会阻塞任务。

角色素材：
在人物属性中可预览动作、表情、方向和姿态，导入本地 PNG 图集与 JSON 清单。
“试用示例素材”提供完整可编辑样例，位于 _internal\materials\crew-avatar-example。
图集只改变人物外观，不更改 Agent 的能力或权限；内置配色表单仅修改内置骨架。
人物属性还可设置“没有工作时”的动作与等待秒数：玩手机、打游戏、浇花、自定义休闲或保持待命。
所有工作、待答复及提醒清空后，最多四项活动每 5–10 分钟随机轮换；接单或点击立即停止。监管员保持值守，不产生额外模型调用。
用户本人不显示为老板人物，默认助手接待；配置成员同任务集合站会，通用外援只保留轨迹，主 Agent 显示电话联系外援。
自绘生活片段使用 phone / game / water / relax 动作名，缺帧时回退内置动作。
点击“试用手绘角色”可导入小禾的视觉样板，“连播核心动作”在表单内预览正背面走跑、起坐和手机。
该按钮保留单角色样板。现在还可选择阿晨、小禾、小岚、监管员并“导入完整角色”，保存前不替换原人物。
完整库共 496 个人物姿态，每套覆盖 20 种动作语义与 5 种闲置表情，v3 支持基础/工作两页图集。
顶部“素材总览”可分类查看角色、12 件家具、16 件装饰和 8 组四帧特效，支持暂停逐帧及真实覆盖矩阵。
常用手绘家具与灯/咖啡机已接入房间；其余装饰与特效按总览详情说明；部分比例、边缘姿态与接触效果仍待精修。
完整说明和源图位于 _internal\desktop\ui\studio\assets\library-v1。

可选旁白：
默认规则即可使用。需要时在模型配置中单独选择“辅助旁白模型”，再勾选开关。
旁白只修饰动作与短文本，不决定任务成败、不授予权限，也不使用执行模型配置兜底。

配置和数据：
默认保存在 %LOCALAPPDATA%\RoomCrew，升级或移动程序不会覆盖它们。
模型配置位于 private\model-config.dpapi，使用当前 Windows 用户的 DPAPI 保护。
可选表现模型独立保存在 private\presentation-model.dpapi。账号级人物与 Agent 定义保存在 data\account.sqlite。
不要将私有配置复制给其他人；不要在会话中粘贴真实 API Key。
模型消息和任务文件可能发给你配置的模型服务商，本地保存不代表离线推理。

范围：
当前支持文件读写与检索、规划、子 Agent 委派、本机时间、人工信息确认、人物持久化和空间原型。
未开放 Shell/任意代码、MCP、浏览器、Computer Use、安全 VM、账号云同步、外部家具/骨骼动画导入与家具拖拽布置。
监管员只是基础设施形象，界面会标明“安全 VM 未接入”；当前不是 OS 沙箱。
每个工作空间同时执行一个会话，最多四个工作空间并行；修改模型配置后需要新建会话。
停止不撤销已完成的文件操作。失败或中断会话仍可查看，继续请新建会话。
公开轨迹不包含模型隐藏思维链；模型正文在一次完整响应后显示。
