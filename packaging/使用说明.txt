RoomCrew · 本地工作空间原型 0.1

运行
解压整个发行包，双击 RoomCrew.exe，保留相邻 _internal 文件夹。
无需预装 Python、Node.js 或数据库服务。
系统前提：Windows x64、Microsoft Edge WebView2 Runtime、.NET Framework 4.8。
尚未提供安装器或签名。仓库开发统一使用根 start.ps1 选择发行与数据目录。

首次使用
1. 打开“模型配置”，手动填写 Base URL、模型 ID、API Key、超时和上下文窗口。
2. 当前支持 OpenAI 兼容 Chat Completions，模型需要标准工具调用。
   可选代理需显式填写；留空直连，不继承系统代理。
3. 点“保存并测试连接”，自动保存当前表单再请求对应服务；保存失败不测试旧配置。
   “仅保存配置”不发请求，API Key 保存后不回显，留空沿用。
4. 在右上角“⋯ → 我的团队”添加和配置成员，人物属性分“Agent 配置”和“员工素材配置”。
   用成员选择框或 @准确名字 指派任务，未指定时由助手接待。
5. 点击角色在右侧打开对话并选定该 Agent，发送时才创建会话；本窗口可回到该成员已发送的对话。
   持久历史仍在左侧会话列表。团队配置从更多选项进入；泡泡用于查看结果或答复问题。
   日记等内容由真实模型与工具生成，程序没有预设任务结果。

工作空间与 Agent
每个工作空间对应一间会议室，可新建、选择和重命名，最多 16 个。
成员、Agent 定义、布局、会话、轨迹、产物和 checkpoint 按空间隔离，切换不停止后台任务。
原数据仍属于默认空间，新空间保存在 workspaces\<空间ID>\data。
只委派本空间显式配置的 Agent；一成员不能并发克隆，不提供隐式通用外援。
每空间同时执行一会话，最多四空间并行；成功会话可续聊，失败或取消会话保留查看。
人物形象可复用 Agent 定义，独立任务使用独立上下文。人物动画不决定真实执行结果。
目前没有空间删除、云同步或跨空间长期记忆；档案室仅为规划入口。

工具与配置
Agent 可编辑系统提示词、Skills JSON、HTTP MCP JSON 和 Python 开关。
Skills 先读名称/描述，再按需加载正文；附带脚本需复制到任务目录再运行。
MCP 仅支持无认证 Streamable HTTP，不支持 stdio、OAuth 和认证 Header，URL 不可包含秘密。
默认加载官方文本读写搜索与 file_info / make_directory / copy_file / move_file / delete_file。
复制和移动保留原始字节、不覆盖已有文件；删除仅支持单文件或空目录。
Python 使用随包标准库解释器、无网络 AppContainer 和受限 Job，不依赖用户安装。
执行默认 30 秒、最高 120 秒；不支持 pip、第三方包、外网和子进程，隔离失败不回退宿主。
只处理任务文件副本，成功后写回产物；停止任务不撤销已完成文件操作。
尚未开放 Shell、浏览器、Computer Use 或完整安全 VM。

人物与素材
默认显示助手和监管员，用户本人不显示老板替身。监管员当前仅展示“安全 VM 未接入”。
空闲活动最多四项，每 5–10 分钟随机轮换，接单或点击立即停止；假聊天不调用模型。
拖动空地平移，滚轮缩放；选择人物后点沙发、工位或会议座换座。
“布置会议室”用格网表单修改位置、方向和座高，不覆盖已有自定义布局。
当前素材是八类设备八向及四角色配套工作/六帧起坐的兼容预览，非全动作最终美术。
配套办公椅限定匹配角色和标准座高 22，任意用户家具不能自动保证自然接触。
“素材总览”可检查实际覆盖；素材与来源见 _internal\desktop\ui\studio\assets\scene-v1 和 scene-v2。
人物支持 PNG+JSON 原两页图集导入，内部补页不改变用户源帧号。
素材配置可按工具、MCP、Python、Skills、人工、完成绑定动作、帧率和循环。
外部家具导入、骨骼编辑器、完整 IK 及家具拖拽尚未实现。

消息与人工问答
每次任务由入口主 Agent 转达完成及人工问题；子任务真实执行者和轨迹仍保留。
泡泡跟随人物和镜头，未读不会因新任务、切空间或重启清除。
完成提示成功打开对应会话后消失，人工问题需实际答复或取消任务；仅关闭弹窗不算答复。
人工窗口居中并虚化背景，可选项或补充输入，答复恢复原 Run；这不是系统权限审批。
会话正文支持 Markdown，代码可复制；工具日志保留原文，HTML 不执行，远程图片不自动加载。
公开轨迹不包含模型隐藏思维链，模型正文在一次完整响应后显示。

配置与数据
默认数据位于 %LOCALAPPDATA%\RoomCrew，显式 --data-dir 可选择其他目录。
模型配置由当前 Windows 用户 DPAPI 保护，位于 private\model-config.dpapi；不放入 Agent 文件视图。
可选旁白模型独立配置，默认关闭，不能改变任务、授权或替代人工答复。
账号成员与定义位于 data\account.sqlite，模型配置由本机用户统一维护。
所有空间的运行与待答复结束后方可修改共享模型配置，变更后需新建会话。
不要分享 private 文件或在对话粘贴真实 Key。任务内容会发送给配置的模型服务商，本地保存不等于离线推理。
